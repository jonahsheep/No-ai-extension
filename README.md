# No AI — Block Google AI Overviews & AI Content

Chrome Manifest V3 extension that **automatically blocks Google's AI Overview** and optionally **all AI content** on Google (higher note).

## Features

- **Auto-hide AI Overview** — CSS hides instantly + `MutationObserver` scans for `AI Overview` heading in 10+ languages and walks up to the block container (`MjjYud`/`g`) so the whole module disappears without touching organic results.
- **Hide AI Mode** — removes AI Mode tab, homepage pill, and any `?udm=50` links.
- **Auto-escape AI Mode** — strips `udm=50` via `history.replaceState`.
- **Higher note — Aggressive mode** — hides Gemini prompts, “Generated by AI” / “AI-generated” badges, AI Images sections.
- **Just the links (udm=14)** — forces Google’s hidden `Web` filter (no AI, no shopping, no knowledge panels).

No tracking, no network requests, no remote config. All settings in `chrome.storage.sync`.

## Install (Load unpacked)

1. Open `chrome://extensions/`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the folder `No ai extension` (the one containing `manifest.json`)
5. Pin the ✦ icon, click it to toggle modes.

## Files

## How it survives Google changes

- Attribute selectors (`[data-attrid*="AIOverview"]`) for fast hide
- **Text matching** for `AI Overview` / `KI-Übersicht` / `Vue d'ensemble`… (Google localizes)
- **Block container walking** (up to 8 levels) to `MjjYud`/`g`/`[data-hveid]` so we hide the entire SERP module cleanly
- SPA navigation handling (`pushState` polling + observer)

If Google changes DOM again: open DevTools → inspect the AI Overview → note its heading/text or attributes → add to `AI_OVERVIEW_RE` in `src/content.js`.

## uBlock Origin alternative

If you already use uBlock Origin, you can use filters instead:

```
google.com##div[data-attrid="AIOverview"]
google.com##a[href*="udm=50"]
```

But this extension is better — it catches localized headings and walks to the correct container.

## Permissions

- `storage` — save toggles & block count
- `host_permissions: *://*.google.*/*` — run only on Google
